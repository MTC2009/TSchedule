# Color system

The [TSchedule campus mark](docs/tschedule-icon/README.md) is supplied brand artwork: use its supplied light and dark renditions in the sidebar and app icon without template tint. The sidebar follows the current App interface appearance, while the home icon respects the OS icon style. These artwork colors are not UI tokens and must not tint student data or controls.

This is the native iPadOS app's color reference. Art colors are not an alternate theme for content. Don't use weather moods to set text, status, control or action colors.

| `color.data.assessmentTrend` | System accent (`Color.accentColor`) | Assessment-history lines and points in the preview and detail chart | Forecast or score text, categorical status, or invented history |
| `color.data.attendanceStatus` | Existing `AttendanceStatus.color`: system blue, orange, pink and purple | Label an attendance status consistently; use its tint on the corresponding ring segment and a solid fill with Reduce Transparency or Increase Contrast | Ranking all courses, weather, or task completion |

| `color.background.seasonalMaterial` | `SeasonalInk` in the native Seasonal renderer: jade/moss/bud for plants, bark/twig for wood, teal/water for reflections, silver/pearl/ivory for moonlit faces and petals, vermilion/berry for lacquer, copper/brass/gold for metal and emissive lights, slate/ink for stone and dark pigment, hay/umber for dried vegetation, chalk for limewashed walls, amber for eyes, rose for vascular tissue | Albedo, emission and reflections on three-dimensional seasonal scenery | Text, controls, status indicators or global UI tint |

Relief-print pigments extend the same seasonal material family: `moonSilk` is the light paper-colored face of the moon hare and star-bridge details; `midnight` is the darkest cut silhouette; `farIndigo` recedes into the distance; `riverMist` separates distant land from the shore; `celadon` marks pale banks and spring foliage. `ghost` is the emission of the ignited Halloween lamp, never a UI success color. Mix these pigments on the scenery only; existing sky tokens, weather and UI colors do not receive the print transfer.

The four-plate detail pass adds finishes, not colors: `carvedInk` varies the existing relief pigment with carved-edge light and shallow shadow; `lotusSilk` mixes `moonSilk` / `blush` for soft petals and a denser rose lip. Neither is a control state or UI tint.

The shared seasonal material palette is defined in `Xiaobao-iPadOS/Sources/Native/Atmosphere/Seasonal/SeasonalScene.swift`. Its perched-sparrow finish has one local set of pigment reflectances in [SeasonalPlumage.h](Xiaobao-iPadOS/Sources/Native/Atmosphere/Shaders/SeasonalPlumage.h): soot/umber for the inner webs, russet and wheat for the mantle and weathered margins, ivory for terminal bars and ash for down. These are physical art pigments, never UI colors or a reference photograph sampled at runtime. Code values for the other background families are centralized in `Xiaobao-iPadOS/Sources/Core/Atmosphere/SkyPalette.swift` and `Xiaobao-iPadOS/Sources/Native/Atmosphere/AtmosphereColors.swift`. `VolumetricSkyState.swift` resolves the semantic sky palette into linear RGB and supplies the sunlight, moonlight and cloud fill tints for Metal. These linear reflectances are lit by the sky, not flat display colors: moisture, metals, plant transmission, fur and paper use their own optical response. Shader scattering and extinction coefficients are not UI color tokens. No runtime sky photo is needed.
