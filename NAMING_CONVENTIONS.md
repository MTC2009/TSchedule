# Naming conventions

- For school reads, `notReady` means a document is not ready for a read, `expired` means the service explicitly rejected a previously verified session, and `login` means student interaction is needed (including first login). `denied` means the requested information is not accessible; it is not an instruction to authenticate.
- **Foreground school sign-in** is a new authentication using a student's opt-in local **binding**. It is distinct from ordinary session recovery. `interaction` stops automatic sign-in (a challenge or unfamiliar flow); a **paused** binding cannot release another password before successful verified completion or deliberate re-enrollment.
- `signInTimeout` means no sign-in outcome arrived by the local deadline. `signInRejected` is an explicit refusal on the school page, not an inference from a disabled button. Neither authorizes another submission.

- **School portal** (`SchoolPortal`) is the official student website session. **CampusConnection** remains the optional demo HTTP service; neither shares tokens or caches with the other. A portal **week** is actual dated records, not a rotation template. The **saved school timetable** (`SchoolTimetable`, 学年课表) is the separate protected device copy. A **rotation** is corroborated against dated teaching Days in the published calendar, not inferred from weekdays. A portal **epoch** invalidates all in-flight reads after a session transition. **已保存成绩** refers only to the last successful, registered, owner-and-term local publication, never a forecast or permission to read. **临时系统遮盖** pauses interaction without ending the foreground display session.

- Rust directories, files, functions, variables, modules, tests and fields: `snake_case` (`mod.rs` is the module entry). Rust structs, traits, enums and enum variants: `PascalCase`. Constants and application environment variables: `UPPER_SNAKE_CASE`.
- HTTP paths use lowercase words and `kebab-case` for multiword segments. Existing versioned endpoints remain under `/api/v1`; field, filter, database column and error-code names use `snake_case`. HTTP methods, paging and response/error formats follow [API.md](xiaobao-backend/API.md). So do identifiers, optional/null values and ISO dates/timestamps. There is no application event bus; use `snake_case` if an event name is introduced.
- `work` is the shared collection, `kind` is `task` / `exam` / `evaluation`, and `work_type` is a source category within a kind. `status` describes completion/submission, `grading_status` describes grading. `score_rate` and `present_rate` are numeric ratios, not formatted percentages. `term` is a stable term ID, not a display label.
- Task `published_at` is the original publication date/time, distinct from `opens_at`, `due_at`, and `submission.submitted_at`. `current_term` and `available_terms` describe the authorized task directory, not grades. **本地完成** never changes the source submission or grading state. A missing grading field is not **未批改**; **批改中** is reserved for an explicit in-progress state.
- Read handlers use `list` for a collection, `detail` for a single record and `read` when the module serves one report. Use descriptive test names for externally observable behavior, in `snake_case`.
- Swift follows the native project: `PascalCase` source filenames and types, `camelCase` functions/properties/constants, descriptive `test...` methods. Use **weather** for the selected condition, **sky time** for the date-adjusted visual clock (not the school schedule clock) and **weather frame** for values at a particular moment of an effect. Weather titles are labels, not persisted identifiers; existing raw identifiers remain decodable.
- **City weather** is the public fixed-city input. `validAt` is the time described by its model; `fetchedAt` is the local receipt time. Neither is the user's preview time, a station observation or the school's last sync.
- **Festival** remains the saved manual sky selection (existing raw IDs remain valid). **Solar term** means one of the 24 named solar-calendar dates; Qingming and the winter solstice have one scene each. **Seasonal** names code for this decorative geometry, its local motion and its transient hit targets. It never names a school closure.
- **Teaching slot** is a published instructional interval (`TeachingSlot`, JSON `teaching_slots`). **Free Block** is the student-facing name only for a whole teaching slot without an overlapping lesson; it is not a course, recess or lunch. Swift represents it with `LessonTimeline.Block.freeblock`. The Simplified Chinese label is **空节**; the English label is **Free Block**.
- **Block 9 / Block 10** are the school’s optional after-dismissal periods (same labels in both languages), never Free Blocks. **Boarding routine** is a local Planner display choice (`showsBoardingRoutine`), not an enrollment or a school profile field.
- **Campus activity** (`LessonTimeline.Block.activity`) means a school-wide interval, not an enrollment, teaching slot or inferred Free Block. Kinds are `assembly` (**班会**) and `lunch` (**午餐**); neither is transmitted as an enrolled lesson. **Elapsed** describes time on this strip, not attendance, a submission or a completion flag.
- **Break** (**课间**, Swift `recess`) is a confirmed pause between two timetable blocks inside a campus bell recess. It is not a Free Block, a lesson, or a separate timeline tile. Unknown or off-day gaps are not labelled Break.
- **Published school calendar** (`PublishedSchoolCalendar`, offline `school_calendar`) is a dated and scoped publication, not a roster. `calendar_day.day` is the printed Day; top-level `schedule.day` is the teaching-template index. **Unpublished** (`unpublished`, **尚未公布**) is not **No class** (`no_class`, **不上课**). A **timetable week** (`TimetableWeek`) is a Sunday–Saturday date range for Planner's week view and weekly plans, not a separate native page.
- **Timetable category** (`TimetableCategory`) is a display choice, not a registration. A **supplemental course** (`PersonalPlan.courseKind`, `SupplementalCourseKind`) is an explicitly timed personal record, never an official school enrollment. A timeline **reference** (`LessonTimeline.Block.reference`) carries a local label and interval without a school course-detail ID. **External exam course** names a curriculum, not an exam event.
- **Planner** is the native **计划** page. A **personal plan** (`PersonalPlan`) is an editable on-device record for one school date; a **school entry** (`PlannerSchoolEntry`) is read-only. **Unscheduled** (**待安排**, `unscheduled`) means the plan has a date but no time. **Completed** (`isCompleted`) applies only to personal plans in this page, not elapsed time or a school submission.
- A **plan range** is a personal plan's explicit start and end. **Range selection** (**选时段**) fills an unsaved editor draft; moving a saved range by its handle is **placement**. **Plan color** (`PlanColor`) and **plan icon** (`PlanIcon`) are optional stable identifiers, not status values.
- A **plan bubble** (**计划气泡**) is a shelf affordance. A **reusable bubble** (`PlanBubble`, **常用气泡**) is a saved recipe that can create independent dated plans. A **recurring occurrence** is a dated projection with its own completion. A plan’s **recurrence** (`PlanRecurrence`) is either a Shanghai **weekday** (1 = Sunday) or a published **rotation Day** (1–6 on teaching dates only); neither implies the other. A **plan reminder** (`PlanReminder`) is the optional lead before a personal plan, distinct from the school lesson reminders.
- **Browse / Edit** describes the Planner's gesture mode, not a plan status. Moving a **recurring series** revises its weekday or rotation Day and time from the effective date; **Undo / Redo** (**撤销／重做**) are session-only personal edits. **Remove** (**移除**) cancels a personal occurrence, unlike **Unscheduled**. **仅这次** excludes its date; **这次及以后** ends the series from that date inclusive. A **school notice** shows published timing or no-class status, never a personal plan.
- **GPA** is the native page name, not a rename of the school web entry. A **course total** (**课程总评**) is distinct from an assessment result or a term GPA. An **assessment group** (**评估分组**) is a source-defined category which may include child groups or assessments, or still be empty, not a course. An **assessment weight** (**权重**, API `weight`) is a fraction with a course or group scope; it is neither a score rate nor an assumed equal share.
- A **credit-weighted estimate** (**估算 · 按学分加权**) is derived from published course data and confirmed school rules. **试算** refers to the separate local what-if tool. **Pending publication** (`graded_unpublished`, **已批改，待发布**) is an explicit source state. A **released score estimate** (`released_score_estimate`, **预估分**) is an authorized nonofficial preview, not a published mark.
- An **assessment forecast** (**预估任务**, Swift `AssessmentForecast`) is a user-entered assessment, not a source record. Live-school drafts persist by verified owner, term and course. A group anchor resolves its location against that course's current groups instead of assuming positional IDs are stable. A group share is its published fraction of its parent (or course); it is not a single task’s course weight. A **forecast course total** (**预估总评**) is the result of that what-if calculation, never an official total or a term GPA. **预测 GPA** is a separately labeled term estimate using the forecast course totals and the OpenGCalc model. A **forecast group subtotal** (**预估组分**) is the estimated percentage of an edited leaf, distinct from that group's weight.
- **其余项目** (`AppTab.otherItems`) is one native sidebar destination. Its page-level **考试 / 测评 / 资料库** selection is `OtherItemsSection`; it does not rename school portal sections, work kinds, or cache keys.
- **未分科** (`OtherItemsFilters.Course.unassigned`) means there is no known source course relation for the item. An item with a linked ID but a roster name not yet loaded remains assigned; do not derive a course from a title, sharer or generalized label.
- **School attendance query** (`SchoolPortalAttendanceQuery`) selects a category, date bounds, status and page in the current school session; a **subject** detail is an individual course from that report, never a selectable student. The school’s overall rate is optional and separate from the four counts.
- **Lesson activity** (`LessonActivity`) means the foreground-started ActivityKit snapshot of one ongoing lesson, not a reminder or a scheduled background read. End time refers to the current period; next course refers to the next unambiguous class in the same loaded day.
- **Attendance composition** (`AttendanceComposition`) is the distribution of the four recorded statuses within one report or one course. A segment is a fraction of that input's total, not of the largest course or of all courses. An unavailable count is not a confirmed zero; the published `present_rate` is still a separate field when reading connected reports.

- App-owned language belongs in the [native string catalogs](Xiaobao-iPadOS/Sources/Core/Localization/README.md). Keep domain identifiers separate from translated labels; school-supplied display strings and personal input are verbatim, not localization keys.
