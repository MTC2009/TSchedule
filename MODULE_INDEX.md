# Module index

`<repo-root>` denotes this repository. All paths below are relative to it; e.g. `Xiaobao-iPadOS/` means `<repo-root>/Xiaobao-iPadOS/`. The shipping app uses the verified on-device school portal session. Local teaching fixtures and the [Rust test service](xiaobao-backend/README.md) are developer-only. No Schoolis records pass through Rust.
