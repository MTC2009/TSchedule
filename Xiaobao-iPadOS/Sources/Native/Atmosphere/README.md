# Atmosphere renderer

- **Responsibility:** fill the host viewport with decorative sky, light, precipitation, visibility and seasonal art. No content layout, school data or service calls. Only the separate [seasonal input path](Seasonal/README.md) handles contacts on visible scenery without taking ownership of foreground gestures.
- **Input / output:** `AtmosphereView(inEnvironmentPanel: Bool = false, isCovered: Bool = false)` draws from `AppModel` and the host environment. A covered navigation root pauses its own drawing; the frontmost environment sheet can animate independently. Inactive scenes, Reduce Motion, Low Power Mode, or a disabled motion preference use a still frame.
- **Dependencies:** Atmosphere core, SwiftUI Canvas, MetalKit and the compiled local Metal shader. No background images or videos; both three-dimensional GPU caches are generated by compute kernels.
- **Consumers:** `RootView` owns one main sky in the split detail column; `StudentDetailSurface` and `EnvironmentView` retain their own existing surfaces. See [Reusable modules](../../../../REUSABLE_MODULES.md).
- **Files:** `SkyBackdrop` hosts a Metal surface and gradient fallback, `SkySurface` schedules bounded drawing, `VolumetricSky` builds shared immutable GPU resources and encodes each draw, `VolumetricSkyState` resolves independent light and motion values, and `Shaders/` integrates cloud density and self-shadowing. `WeatherOverlay` and `SkyParticles` add visibility and precipitation, and `SkyDetails` builds the [Metal seasonal scene](Seasonal/README.md), including 13 festive relief prints and 24 interactive solar-term studies. Only seasonal pigments receive the print finish; the sky itself remains natural.
- **Performance:** initialization is off the UI thread; per surface one frame may be in flight. The active surface requests 24 frames/s and adapts pixel and sample budgets. Static or reduced-motion mode pauses the cloud clock and redraws only when inputs or viewport change. The ordinary SwiftUI fallback is a code gradient if the device cannot create or run the pipeline.
- **Tests:** run `scripts/render_sky_probe.sh` with a new output directory, or compile the shared scheme for an iPad simulator and compare night frames at a held clock with motion on/off. The probe verifies deterministic repeat frames and distinct elapsed-time output using the same pipeline as the app.
- **Limits:** decorative cloud motion and lighting, not a physics simulation or meteorology report. No physical-iPad frame rate, heat or battery-life claim.

## Change History

### 2026-11-22 — canonical-bells / named-school-cards / seasonal-pause
Model: OpenAI Codex. The app skips seasonal renderer/mesh creation and does not mount seasonal interaction. Time, weather, cloud lighting and precipitation still use the ordinary pipeline. Interface: shipping availability is controlled by the optional `TSCHEDULE_SEASONAL_ART` compilation condition; no preference is erased.


### 2026-11-22 — Articulated print materials
Model: OpenAI Codex · Keywords: carved-ink / lotus-silk / mirror-waterline
Changed: The seasonal shader has two opt-in finishes: shallow ink carving with the existing light-space shadow, and diffusely lit lotus silk with a restrained rim wash. The shared seasonal camera, render passes and existing matte silhouettes are unchanged.
Reason: Read deep and overlapping cuts at display scale without relighting the moon hare, the sleigh or the sky. Affected interfaces: internal finish tags only; [plate geometry and validation](Seasonal/README.md).

### 2026-11-22 — Seasonal foreground and airborne motifs
Model: OpenAI Codex · Keywords: relief-prints / town-occlusion / angular-moon
Changed: Grounded opaque art hides the sky; openings still show clouds. Airborne motifs retain volume-tested visibility. The Lantern Festival mixes both at separate depths: the close lamp stays in front, independent distant fireworks and sky lanterns remain in the cloud pass. Balanced/high quality resolves four geometry samples (not four cloud integrals) for the seasonal pass. The cutout, refraction and pick resolve use the same sample positions, with a lower resolution path when a fine bank does not fit. A scene receives the exact sky moon direction and radius, and a visit-local seed for Spring Festival and Lantern Festival.
Reason: Keep ink edges sharp, stop distant clouds bleeding through a wall, and keep flight silhouettes in proportion when rotating the device.
Affected interfaces: internal encoder, local scene construction and material targets. No changes to `AtmosphereView`, interface controls, forecast or stored preferences.

### 2026-11-22 · Perched-bird detail
Model: OpenAI Codex · Keywords: conditional-feather-bank / subpixel-coverage / paused-redraw
Changed: On the first Lesser Cold request, a shared detached task prepares static bird geometry. A surface can keep drawing the normal sky while waiting and redraw a paused view when the bank becomes available. Only that recipe requests four geometric samples per output pixel; cloud integration and the visible picking attachment stay at the ordinary output resolution.
Reason: Avoid paying wildlife setup cost on an ordinary date or aliasing thin flight feathers into disconnected dots. Per-surface sample targets are reusable and fall back to ordinary geometry resolution if allocation fails.
Affected interfaces: internal renderer prewarm and geometry target selection only; no change to the SwiftUI host, scene clock, accessibility policy or account.

### 2026-11-22 — Shared-light seasonal rendering
Model: OpenAI Codex · Keywords: seasonal-lookdev / reflected-camera / procedural-finish
Changed: Optional seasonal path now shades species-specific solids under the existing sky lights, renders caster depth, and conditionally captures the opaque scene and a half-resolution mirrored water view. Local light can scatter in procedural firework smoke. Raw IDs/ranges remain independent of defocus and light halos.
Reason: retain the original weather renderer and navigation lifecycle while improving the photographed detail of the scenery. Interfaces: `AtmosphereView`, public weather and calendar selection unchanged; the art and lighting contracts are internal to [Seasonal](Seasonal/README.md).

### 2026-11-21 — Three-dimensional seasonal scenes
Model: OpenAI Codex · Keywords: seasonal-geometry / cloud-depth / visible-input
Changed: Replaced seasonal Canvas artwork with two optional Metal passes, an on-demand ID readback, an independent per-surface reaction state and a local light for the cloud volume. Weather particles are unchanged. Reason: real geometry can move behind clouds and retains its shape when time stops. Affected interfaces: internal encoder and `SkyBackdrop` / `SkySurface` exposure state; the public `AtmosphereView` host interface is unchanged.


### 2026-11-21 — Persistent sidebar sky
Model: Codex · Keywords: sidebar-sky / navigation-scope / draw-pause  
Changed: The main sky is a sibling of the keyed foreground navigation, not part of each tab. It pauses when a destination covers the root, then resumes the same playback clock. The root container is transparent to the sky. No shader, palette, sheet, clock or accessibility policy changes. Affected interface: optional `isCovered` on the existing native view.

Reproduction and rejected approaches: six ordinary sidebar switches formerly created seven Metal views. Attaching a `.background` directly to the keyed foreground also recreated it on the iPad. Conversely, keying only an inner stack did not reliably drop a pushed SwiftUI destination after a session change. The split itself is therefore keyed only to the active account/access boundary, never to the sidebar tab. See the [simulator regression](../../../Tests/AtmospherePreview/README.md).

Verification: on the iPadOS 27 simulator the same six switches retained one Metal view. Switching away from a detail, pausing and resuming behind a push/pop, discarding a detail on session invalidation, and keeping the independently presented sheet all passed. An OS-composited synthetic screen showed clouds behind the native controls. The 179 Swift and 13 portal-reader tests passed; the Release app was updated in place on the target simulator. No student session was inspected.
