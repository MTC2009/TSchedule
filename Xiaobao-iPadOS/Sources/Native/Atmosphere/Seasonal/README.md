# Seasonal · 时令套色版画

**发布状态：暂停。** 正式版不加载以下场景；本页记录保留的美术与独立开发预览，不代表这些效果当前在 iPad 上显示。

**用途与边界。** 用有厚度的轮廓、分色和不同的观察距离，在现有 Metal 天空里画节日与节气；美术自身统一，不要求复制天空的画风，不决定放假、学校日程、天气或业务数据。一个日期只取一个场景。日常不建立时令渲染目标；没有 Metal 时保留原有渐变，不用二维图代替三维美术。

**输入 → 输出。** [日历与动作规则](../../../Core/Atmosphere/README.md)选出 `Festival`；每个可见的 `SkySurface` 独立持有播放时钟、动作和渲染目标。`SkyDetails.scene(_:aspect:time:motion:moon:)` 把状态编成一帧网格实例和可选的局部光源。深度测试选最近表面；几何通道写线性光色、眼距和对象编号。贴地构图的不透明墙、山体和植物遮住后景云；孔洞、天空和未覆盖的边缘仍能看见云。空中角色与烟花按实际眼距受云遮挡。元宵同一景内区分近挂灯和远空：近灯保留完整纸面，远处放飞的天灯与烟花接受体积遮挡。月盘和玉兔的视觉尺度使用同一组投影参数。普通天气的 SwiftUI 降水层是另一个模块，不是时令美术的实现。

**入口与依赖。** `SkyDetails.scene(_:aspect:time:motion:moon:)` 是场景入口。只依赖系统 Metal、simd、UIKit、已有的云密度场和天空色彩。没有网络、下载模型或美术图片；GPU 中用来保存深度、辐射亮度、折射底色和体积密度的纹理是现场计算的缓冲，不是贴在模型上的图片。

| 实现 | 职责 |
| --- | --- |
| `SeasonalScene`、`SeasonalGeometry`、`SeasonalSculpt` | 坐标与材质、一次生成的共享三角网格；定形用截面、曲面和实体羽束；近景的翅膜、花瓣、抽穗、屋瓦和器皿均有独立轮廓。 |
| `SeasonalRelief` | 闭合的三次曲线轮廓带正面、背面和侧缘；兔耳、喜鹊飞羽、划手侧脸、龙首、桥心小径、山路和亭檐都用实际几何留出负形。 |
| `SeasonalWildlife`、`SeasonalBotany`、`SeasonalHabitat`、`SeasonalSetPieces` | 分别组装昆虫、植物与水面、24 个独立观察位置与配景、小屋。远景不抢占交互目标。 |
| `SeasonalRegatta`、`SeasonalWaterline`（在 `SeasonalBotany`） | 船壳与舷线由同一横截面生成；双排桨、船首水痕和贴水荷叶读取当前场景的**镜像平面**，不另设屏幕水线。 |
| `SeasonalSparrow`、`SeasonalPlumage`、[雀羽材质](../Shaders/SeasonalPlumage.h) | 栖枝雀专用的头胸截面、上下喙、眼睑、足爪、短羽毛束、覆羽和闭合翅尾；不替换飞燕或喜鹊。 |
| 四季文件、`SeasonalHolidays`、`SeasonalFestivalLandscapes`、`SeasonalFestivalCourtyards`、`SeasonalFlights` | 六景一季；节日的水乡、赛舟、鹊桥、山径与檐下雕灯；烟花与天灯按每次进入的种子和事件编号变化。各时令保留自己的交互规则。 |
| `SeasonalShadow`、`SeasonalRenderer`、[材质响应](../Shaders/SeasonalSurface.h)、[照明](../Shaders/SeasonalMaterials.h)、[镜头](../Shaders/SeasonalLens.h) | 复用同一帧实例画太阳／月亮深度、实体表面、按需的水面镜像和折射，最后由原天空进行体积遮挡与镜头合成。 |
| `SeasonalContact`、`SeasonalPicking` | 非排他手势、可见表面命中和局部异步回读。不保存触碰记录。 |

**如何判断细节。** 看同一物体转向、移动、被遮住或受光时的变化，而不只看静态花纹。弯曲枝梢和芦穗的影子来自实际网格；昆虫翅膜和露珠读取后方实物的颜色；湖中龙舟由绕水面翻转的相机再画一次，波的法线扰动倒影。火星、飞絮、丝穗和涟漪都不是面向相机的精灵。岸线、苇丛与近景标本离同一焦平面的距离不同，虚实程度也不同。镜头虚化和眩光不扩大命中范围。普通日期不建立时令绘制目标或额外绘制通道。

**命中与动作。** 光照合成后保留可见表面的编号和距离；`SeasonalPicking` 只在一次触摸开始时回读落点附近的小块编号，而不是读取屏幕画面。空处、深云后面的角色、被前景控件占用的触点不触发。只在可见的交互场景挂载 `SeasonalContact`；它不取消其他手势，原生控件、表格行和滚动优先。横向轻拨可以持续弯动主体，松手释放；普通点按也能触发。覆盖或切换场景会作废未完成的命中。减少动态效果或低电量时不连续播放，主动碰触可显示同一场景的一个反馈姿态。

### 节日主景

| 节日 | 能看到什么 |
| --- | --- |
| 元旦、除夕 | 两岸粉墙、黛瓦与真正通透的石拱，沿河台基托住房屋；除夕从另一个位置看窗灯和一串垂下的红灯。 |
| 春节 | 随机错时升空、绽开、下垂、熄灭；位置、纵深、颜色、花型和余烬随每次发射而变，冻结的同一帧不闪跳。 |
| 元宵 | 近处花灯有灯骨、挂珠与垂穗。远处九道天灯各有自己的放飞时刻、摇摆、风向偏移与明暗；另外两道较慢、较远的小烟花随机升空和散落。 |
| 端午、七夕 | 朱漆船身吃水，双排桨依次入水、拉桨、出水，鼓手在鼓后交替击打。七夕以交叠的羽尖托住桥心，牛郎和织女有不同侧影，空中的两股鸟群穿过桥拱，并非固定在桥面上扇翅。翼斑沿真实翼缘嵌入，翻面时不脱节。 |
| 中秋 | 暖色圆月旁，宽约月亮直径八成的白色剪影间歇从右向左飞。点中会提前下落，不影响下一趟。 |
| 重阳、万圣夜 | 山路、行人、松与亭共用同一山脊标高，前景是菊花；万圣夜在右侧半幅瓦檐边悬一盏雕灯。只点中灯才会亮绿火，眼口冒焰，弹三下后转一圈，再恢复琥珀色。 |
| 感恩节 | 敞开的厨房窗台摆着编篮、秋果、玉米和一支烛灯。按美国感恩节日期出现。 |
| 平安夜、圣诞 | 同一轮日常月亮。平安夜是较远的银白剪影，圣诞近一些且保留朱红车身，均从左向右飞。点中可能无事发生，也可能有礼盒从当时的礼物袋位置翻滚落下，两种结果都不改变飞行。 |
| 跨年夜 | 双檐钟亭悬钟轻摆，岸灯倒映在水面，钟点波纹把倒影推开。 |

以上是 13 个独立节日主景。清明、冬至各用下表的同名场景；不重复叠加。天灯在此套画中留给元宵，以便和中秋的月兔构图区分；并非各地只在元宵放灯。[平溪元宵天灯](https://newtaipei.travel/zh-tw/column/860)与[东莞南城旧时中秋民俗](https://www.dg.gov.cn/nancheng/nczwz/ncdafzgwz/pzwh/ftms/content/post_2395851.html)各有记录。

### 24 个节气的触碰反馈

水景另外支持点水：波从命中的水面位置扩开，改变三维网格及其反光，而不是固定在屏幕中央。

| 春 | 夏 | 秋 | 冬 |
| --- | --- | --- | --- |
| **立春**：嫩芽向外舒展 | **立夏**：荷尖摇动，蜻蜓收拢翼尖 | **立秋**：拨叶，叶片翻出另一面再回摆 | **立冬**：添亮窗内暖光，光落到窗前的枝条 |
| **雨水**：叶尖水滴坠入水中 | **小满**：饱穗受力弯下，松手回弹 | **处暑**：风拨过芦穗，草籽随风散开 | **小雪**：一小撮芦絮从穗上散开 |
| **惊蛰**：甲虫收足退到叶背，再探出来 | **芒种**：靠近触点的一簇秧苗挺起 | **白露**：露珠沿叶面滚下 | **大雪**：白芦成片倒伏，动作从触点附近向两侧传递 |
| **春分**：两燕掠低，振翅回升 | **夏至**：树冠摇动，短影也跟着摆动 | **秋分**：摇桂枝或点开倒影附近的水面 | **冬至**：低枝摆动，地上的长影收短、复位 |
| **清明**：柳丝随手偏转，也可直接点水 | **小暑**：萤火向触点聚拢后散开 | **寒露**：波从触点沿张紧的蛛网传开，露珠随丝走，枝杈不动 | **小寒**：枝头寒雀蓬起羽毛，伏低再放松 |
| **谷雨**：拨开茶梢，露出内侧的新芽 | **大暑**：外瓣先展开，内瓣随后放开莲心，再缓缓收回 | **霜降**：叶片转动，铜色向朱红过渡 | **大寒**：梅苞舒成花瓣，再慢慢合拢 |

**小寒的参考与观察尺度。** 栗冠、浅颊和栗色背羽的依据可对照[香港观鸟会的山麻雀物种记录和照片](https://avifauna.hkbws.org.hk/species/0430/052600)；用于确定绘制方向，不鉴定外部样片，也不随 App 分发照片。先在正常界面距离看喙、眼、尾和握枝轮廓，再按同一视点检查近处羽缘；在另一侧看远翼、角膜和脚趾是否仍成立。胸颊软羽由贴着皮肤生长的三维羽枝束组成，硬羽有曲面、羽轴纹和延伸到羽缘的实体羽枝。触碰时末梢抬起、身体伏低，枝和爪不动。

**怎么测。** `swift test --filter SeasonalSceneTests` 检查日历与动作边界；[外观与触控探针](../../../../Tests/AtmospherePreview/README.md)分别验证 GPU 输出和模拟器真实输入。离屏测试镜头不进入 App。以游戏内观察距离判断辨识度与构图，不用像素变化测试替代美术判断，也不以拟真程度给场景排序。材质不是实测光谱；云和水的散射经过简化，镜头是屏幕空间近似。反射相机不递归绘制透明物；极细绒毛和花蕊受设备自适应分辨率限制。没有真机帧率、功耗或热表现结论。

### 2026-11-22 — 水线、羽桥、莲瓣与蛛丝校样
Model: OpenAI Codex · Conversation Keywords: regatta-waterline / interlocked-wing / lotus-whorl / anchored-silk
Changed: 端午用同一镜面约束船壳与十二支桨，桨尖出水才带起水痕；鼓、鼓槌与双手共用节拍。七夕只在两人脚下保留短桥面，外段由羽形搭接，两道人影与两股穿行的鸟群分别造型，翅上的月白羽斑不再是悬在翼面的椭圆亮点。窄窗留出龙首与花瓣的余量，宽窗的飞鸟在画外接续。大暑独用闭合的莲瓣曲面、渐淡的唇色、金色莲心和延时开放的三层花瓣，叶盘按同一水面放置。寒露的螺旋与辐丝用共享绳结，露滴贴弯曲丝线，触点改变波抵达各处的时刻。
Reason: 同光线实渲中，强行上下挪船仍会在另一个划桨相位离水；整片实心羽桥和给一条曲线挂等长羽片分别读成色带、鱼骨；泛用重瓣花从正面盖住花心；随整个蛛网移动的露点无法表现张力。校样以这些结构关系为判据，而非给整幅调色或提高截图分辨率。
Affected interfaces: 仅私有网格／材质编号追加、场景局部水线及开发探针；不改变日历、选景、手势目标、存储或在线接口。见[回归与实渲](../../../../Tests/AtmospherePreview/README.md)。

### 2026-11-22 — 时令版画重构
Model: OpenAI Codex · Conversation Keywords: almanac-relief / measured-moon / seeded-lanterns / eave-ignition
Changed: 13 节日和 24 节气统一套色。每景有自己的主体、支承、观察位置和留白；中秋和平安夜用轻薄的实体剪影。平衡及高画质分开采样几何边缘，不额外提高云的采样率。万圣夜动作分段，节气和飞行命中仍由最终可见表面决定。
Reason: 放大人物再堆表面细节，不会改善主体与月亮的比例；等间距排鸟也不能表达相会。元旦的墙上有云，是把室外体积光或失去权重的边缘覆盖当成了前景透明。采用地景遮挡后，另补了台基并让远山延伸到画外，避免露出悬空墙脚和山体切面。
Affected interfaces: 内部场景接受同帧月盘方向／半径；动作接受每次选景种子，万圣夜的点按复用既有 subject 编号。日历、天气选择、页面与服务不变。下列同日近摄和写实记录为先前迭代，非整套当前风格要求。

### 2026-11-22 — 栖枝雀近摄复查

Affected interfaces: 时令模块内部网格分库、渲染目标和羽材质；没有新的用户界面、账户接口或持久化数据。只有小寒使用新增外观；展翅飞鸟、玉兔和雪橇不是此次近摄验收的对象。
