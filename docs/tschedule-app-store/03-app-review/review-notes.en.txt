TSchedule is an independent, iPad-only student companion. Its current interface is in Simplified Chinese. It does not create a separate TSchedule account, sell access, or submit or edit school records.

Live academic records require an existing student account on the supported school portal. Users connect through the school’s official web page inside the app. The authenticated session is used to read the current student’s authorized timetable, tasks, released grades, and attendance. The native app does not send those records or portal credentials to a developer-operated server.

There is a separate optional saved sign-in in Settings > Personal Info > Campus Data (设置 > 个人信息 > 校园资料). It is off by default. If a student explicitly enables it, the account credential is kept in the device-only Keychain and may be used once for eligible reauthentication on the official portal: on a foreground launch if expressly enabled, or on a deliberate grade visit. Launch recovery does not read grades. It can be removed in Settings. The basic portal login does not require this feature.

Weather optionally requests a fixed Dongguan city report from Open-Meteo; it does not access the device’s location or send academic records to the weather provider.
