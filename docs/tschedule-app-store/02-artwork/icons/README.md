# TSchedule 图标

- [默认浅色](tschedule-light.png)
- [深色](tschedule-dark.png)

两张均直接复制自当前 Xcode `AppIcon.appiconset`，均为 **1024 × 1024 不透明 PNG**。请选择实际签名构建中的图标，不要用未接入的设计候选替换附件。App Store 图标由提交的构建提供，不需要把这两张当作商店截图另外上传。

原工程资源：`Xiaobao-iPadOS/Resources/Assets.xcassets/AppIcon.appiconset/`。截图用的侧栏标志来自工程中的同一套产品身份资源。

[Apple：在 Xcode 添加 App 图标](https://developer.apple.com/help/app-store-connect/manage-app-information/add-an-app-icon)
